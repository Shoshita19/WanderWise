# WanderWise – Smart Travel Planner 🌍

WanderWise is a travel planning website that helps users explore destinations, discover places based on their interests, and plan trips according to their budget.

### Features
- Explore destinations with photos, descriptions, ratings, and estimated costs.
- Search and filter places based on interests and budget.
- Generate personalised travel suggestions based on budget and trip duration.
- View estimated expenses and a day-wise itinerary.
- Save favourite destinations to a wishlist.
- Save and manage previously generated trip plans.
- Responsive design for desktop and mobile devices.

### Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite

### How to Run
1. Install Python and Flask.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Install Flask using `python -m pip install flask`.
5. Run `python app.py`.
6. Open `http://127.0.0.1:5000` in your browser.

**Note:** Destination costs and transport prices are illustrative estimates and may differ from actual travel expenses.

This project was developed to practise full-stack web development, database management, and interactive website design.
